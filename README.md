#  AI Chatbot with Claude AI

A beautiful and smart AI chatbot built with 
HTML, CSS and JavaScript powered by Claude AI!

##  Features
- ✅ Real time AI responses
- ✅ Beautiful dark UI design
- ✅ Typing indicator
- ✅ Enter key to send message
- ✅ Smooth scroll
- ✅ Mobile friendly
- ✅ Powered by Gemini AI

##  Live Demo
 [Click here to try it!](https://neha2006-6.github.io/ai-chatbot-js)

##  Technologies Used
- HTML5
- CSS3
- JavaScript
- Gemini AI API
